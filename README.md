# 世界の郷土料理と地球

3Dの地球儀で**高低差・海・川**を確かめながら、世界43か国・**88品**の郷土料理とその背景を学ぶWebアプリです。
同じ国の中でも土地が変われば料理が変わることを、**標高と地形**から見くらべられます。
社会科（世界の国々・世界の地形）、総合的な学習、外国語の文化学習などで使えます。

---

## 使い方

**公開URL：https://sodari65-hue.github.io/world-cuisine/**（児童のiPadはこのURLを開くだけ）

手元のPCでは、`index.html` をブラウザで開くだけでも動きます。インストールは不要です。

- **iPad / 校務PC** … Chrome・Edge・Safari で動きます
- **配布したいとき** … このフォルダごと Netlify Drop（https://app.netlify.com/drop）にドラッグすると
  URLが発行され、児童のiPadから開けるようになります

> **はじめて開くときだけインターネット接続が必要です。**
> 地形テクスチャ（標高・海陸）と国境データを外部CDNから読みこむためです。
> 取得できなかった場合も、料理の紹介・国一覧・クイズは動きます（地球儀は簡易表示）。

## 画面のしくみ

| 機能 | 説明 |
|---|---|
| 地球儀 | ドラッグで回転、ホイール／ピンチでズーム |
| オレンジの点 | 料理が生まれた土地。タップで紹介パネルが開く |
| 国境の線 | 世界のすべての国。国の上にカーソルを置くと国名が出る |
| 水色の線 | 世界の大きな川33本（ナイル・アマゾン・長江ほか） |
| 地形の強調 | ×0〜×70。×0で実物どおり（ほぼまん丸）、上げるほど山が高くなる |
| 高さの色分け | 標高を色で表示（緑=低い／茶=高い／白=万年雪）。凡例の数値は実際の標高 |
| 料理クイズ | 料理の写真と**料理名**を見て国を当てる。**国名を入力**するか、地球儀の点をタップして答える。ひらがな・カタカナ・漢字・英語のどれでも受けつけます（「にほん」「ニホン」「日本」「Japan」、「アメリカ」「USA」、「イギリス」「英国」「UK」など）。答えのあと、その土地と標高つきで解説が出る |
| 検索 | 国名・料理名のほか「発酵」「保存」「海流」「シルクロード」などのテーマ語でも引ける |
| 料理のタブ | どの国にも2品以上。パネル上部のタブで切りかえ（例：日本＝寿司／ほうとう／石狩鍋） |
| 土地のカード | 料理ごとに「生まれた土地の名前・標高・緯度経度・地形タグ」を表示 |
| 地形からくらべる | 左パネルのタブ。9つの地形タグで88品を絞りこみ、**標高の高い順**にならべて見くらべる |
| 国名ラベル | 国が密集する所では自動で間引かれます。ズームすると出てきます |

## 地形からくらべる（このアプリの中心）

料理はすべて「その料理が生まれた土地」をもっています。左パネルの **「地形からくらべる」** タブで、
9つの地形タグから88品を絞りこみ、標高の高い順にならべて見くらべられます。

| タグ | 意味 |
|---|---|
| 🏝 島・島国 | まわりを海にかこまれた土地 |
| 🌊 海ぞい | 海に面し、漁がさかんな土地 |
| 🏞 大きな川のそば | 川が運ぶ水と土にめぐまれた土地 |
| ⛰ 高地・山 | 標高が高く、すずしい土地 |
| 🌾 低地・平野 | 標高が低く、平らに広がる土地 |
| 🧭 内陸 | 海から遠い、または海に面していない土地 |
| 🏜 乾いた土地 | 雨が少なく、水がとても貴重な土地 |
| ❄️ 寒い土地 | 冬が長く、きびしく冷えこむ土地 |
| 🌴 暑く湿った土地 | 一年じゅう高温多湿の土地 |

標高は **2m（ガンボ／ミシシッピ川の河口）から 3,850m（チューニョ／アンデス高原）** まで。
どのタグにも16〜35品あるので、どれを選んでも見くらべが成り立ちます。
タグを選ぶと地球儀のピンもその料理だけになるので、「海ぞいの料理は世界のどこに集まっているか」
「高地の料理に共通する保存のくふうは何か」を、地図の上で確かめられます。

意図的に、国境をこえてつながる組み合わせを仕込んであります。

- **焼けた石で蒸す**… ハンギ（NZ）／ロボ（フィジー）／ピビル（メキシコ）／ホルホグ（モンゴル）

- **凍らせて保存**… チューニョ（ペルー・3,850m）／ストロガニナ（ロシア・シベリア）
- **同じ干しダラ**… バカリャウ（ポルトガル）／アキー＆ソルトフィッシュ（ジャマイカ）

- **サケがのぼる川**… 石狩鍋（日本）／杉板焼きサーモン（カナダ）

## 授業での使い方の例

1. **導入** … 料理クイズで「どこの料理だろう？」と予想させる
2. **調べる** … 地球儀で位置・地形・近くの川や海をたしかめる
3. **読みとる** … 「なぜこの料理が生まれたのか」を3つの視点で読む
4. **まとめる** … 「海に面した国」「山にかこまれた国」「かわいた国」でグループ分けし、料理の共通点を考える

**地形の強調スライダー**は、「スイスは平地が少ない」「ウクライナは平らな大平原」といった
発言のよりどころになります。×0と×40を切りかえて見せると、実感がつかみやすくなります。

**自由進度学習**で使う場合は、各国パネル下の「調べてみよう」がそのまま課題カードになります。
88品×3問で264の課題があるので、児童が国や地形を選んで進めることができます。

## ファイル構成

```
world-cuisine/
├── index.html   画面とスタイル
├── data.js      43か国88品の解説データ・地形タグ・世界の川のルート
├── dishes.js    料理イラスト（自作のSVG。写真が読めないときの予備）
├── photos.js    料理写真の一覧（ファイル・撮影者・ライセンス・出典）
├── photos/      料理写真88枚（長辺800px・合計約7.8MB）
├── credits.html 写真の出典一覧（ライセンス表示）
└── app.js       3D地球儀の描画と操作
```

**フォルダごと**持ち運んでください（index.html だけを移すと動きません）。

## ことわり

- 料理の写真は、ウィキメディア・コモンズの自由ライセンス（CC0・パブリックドメイン・CC BY・CC BY-SA）のものだけを使っています。1枚ずつ目で確認し、人物が写っていないものを選びました。撮影者・ライセンス・出典は各写真の右下と `credits.html` に表示しています。
- 写真をほかの教材に転用するときは、`credits.html` のライセンス表示をいっしょに載せてください。
- 写真が読みこめないときは、このアプリ用に描いたイラスト（dishes.js）が自動で表示されます。
- 郷土料理には地域差・家庭差があります。紹介しているのは代表的な一例です。
- 地球儀の起伏は約1,000×500の解像度のデータによる概算です。細かい地形は表現されません。
- 料理パネルに出る標高は、その土地の代表的な高さとして本アプリが記した目安の値です（地球儀の色分けとは別の数値）。
- フェイジョアーダの由来など、諸説あるものは本文でその旨を示しています。
- 国境データ（110m）には済州島のような小さな島がふくまれていません。そうした場所は地球儀上で
  国の輪郭が描かれませんが、ピンをタップすれば正しく開きます。
